# Project Summary

## Honeypot-Driven SOC & Threat Intelligence Pipeline

### Objective

Demonstrate a simplified defensive Security Operations Center workflow that converts security events into normalized records, detections, threat indicators, and investigation-ready alerts.

### Technologies

Python, SQLite, Pandas, Streamlit, unittest.

### Security Concepts

- Security-event parsing
- Log normalization
- SSH brute-force detection
- Port-scan detection
- Authentication anomaly detection
- Threat-indicator extraction
- Alert triage
- SOC dashboarding

### Scope

The project uses synthetic security events and reserved documentation IP ranges. It is intended for learning and portfolio demonstration and does not perform offensive activity against real systems.

### Learning Outcome

The project demonstrates how raw security telemetry can be transformed into structured evidence and actionable alerts as part of a simplified SOC workflow.
